# ADR-0001: React Router для маршрутизации клиента

- Статус: принято
- Дата: 2026-11-21

## Контекст

Клиенту нужны несколько адресуемых экранов: главная (`/`), страница записи (`/book`) и позже страница владельца. Сейчас в клиенте нет маршрутизации: `App.tsx` всегда рендерит один экран. Ссылки должны быть настоящими URL, чтобы работали прямые переходы, обновление страницы и будущие внешние ссылки.

## Решение

Используем `react-router-dom` (v7) с декларативными маршрутами. Ручной разбор `window.location.pathname` не применяем.

## Рассмотренные альтернативы

- **Ручной разбор `window.location.pathname`** — отклонено: пришлось бы самостоятельно реализовывать историю, прямые переходы, обработку неизвестных путей и переиспользование навигации; при появлении третьего экрана код пришлось бы переписывать.
- **TanStack Router** — отклонено: более тяжёлая настройка и генерация типов не оправданы для нескольких простых маршрутов.

## Последствия

- В клиенте появляется зависимость и единое место описания маршрутов.
- Продакшен-хостинг клиента должен отдавать `index.html` для неизвестных путей (SPA fallback); `vite dev` и `vite preview` делают это по умолчанию.
- Навигация между экранами выполняется через `Link`/`useNavigate`, а не через прямую смену `location`.
